# Arabic glossary for the interface

The Arabic interface (a later plan) is translated from this list, so that one
term always reads the same way on every page. The user checks it first: correct
the Arabic column, or write a better word in "Your correction", and the pages
follow.

Status: **approved by the user, 2026-11-07, as written.** A term changed later is changed here first, then in the pages' catalogs.
Changed 2026-11-08, at the user's request: "Set aside" on a button is now an action, استبعاد من الملف.
Added 2026-11-08, **for the user's review:** [the terms chosen while translating](#chosen-while-translating-for-your-review), which this list did not have.

Notes on the choices:
- **Modern Standard Arabic**, in the register of Saudi government and enterprise software (NCA, SDAIA, PDPL documents): formal, not colloquial.
- **One term per meaning.** "Delete" (gone), "remove" (off this list, kept elsewhere) and "set aside" (not written into the file) stay three different words, as in English (plan 029's analysis, O8).
- **Names stay as they are:** product names (Msegat, Ole5), file names, and standards' names (NCA ECC, PDPL, ISO 27001).
- **Numbers are Western digits (0-9)**, as in the policies and the customers' files. Say if you prefer Arabic-Indic digits (٠-٩).
- **One English, two meanings.** Where English uses one word for a state and an action, the Arabic can differ. The pages key such a term by its meaning (`"action|Set aside"`), and the English reads as before.

### How the Arabic is written

- **Quotation marks** are « » around a name or a title: حذف «{title}».
- **Counts** take Arabic plural forms, or a phrasing that works for every number: "ستُكتب في الملف: 3".
- **Percentages** show as "%90" after Arabic letters. That is how a browser lays out a number in Arabic text, and it is correct.
